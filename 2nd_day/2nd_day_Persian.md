# روز دوم | مدیریت فایل و Jinja2

**هدف:** از چند متغیر، یک فایل تنظیمات واقعی بسازیم و تغییرات را ایمن مدیریت کنیم.

[English](2nd_day_English.md)

| موضوع | ابزار | کاربرد |
|---|---|---|
| پوشه و مجوز | `file` | `/opt/ansible-demo` |
| قالب و شرط | `template` + Jinja2 | `app.conf` |
| یک خط | `lineinfile` | `managed_by` |
| چند خط | `blockinfile` | `notes.txt` |
| بررسی و دریافت | `stat`, `fetch` | `fetched/` |

## ساختار


## کد مشترک دو زبان

```yaml
---
# Day 2: file operations and Jinja2 templates (Debian/Ubuntu lab).
- name: Manage an application configuration
  hosts: lab
  become: true
  vars:
    app_dir: /opt/ansible-demo
    app_port: 8080
    app_environment: staging
  tasks:
    - name: Create application directory
      ansible.builtin.file:
        path: "{{ app_dir }}"
        state: directory
        owner: root
        group: root
        mode: '0755'

    - name: Render configuration from a template
      ansible.builtin.template:
        src: templates/app.conf.j2
        dest: "{{ app_dir }}/app.conf"
        owner: root
        group: root
        mode: '0644'
        backup: true

    - name: Ensure a configuration line exists
      ansible.builtin.lineinfile:
        path: "{{ app_dir }}/app.conf"
        regexp: '^managed_by='
        line: managed_by=ansible

    - name: Add a managed configuration block
      ansible.builtin.blockinfile:
        path: "{{ app_dir }}/notes.txt"
        create: true
        mode: '0644'
        block: |
          environment={{ app_environment }}
          port={{ app_port }}

    - name: Inspect the rendered configuration
      ansible.builtin.stat:
        path: "{{ app_dir }}/app.conf"
      register: config_stat

    - name: Show file status
      ansible.builtin.debug:
        msg: "Configuration exists: {{ config_stat.stat.exists }}"

    - name: Download configuration to the control machine
      ansible.builtin.fetch:
        src: "{{ app_dir }}/app.conf"
        dest: fetched/
        flat: false
```

## قالب `templates/app.conf.j2`

```jinja2
# Generated by Ansible; edit the template, not this file.
[app]
port={{ app_port }}
environment={{ app_environment }}
{% if app_environment == 'production' %}
debug=false
{% else %}
debug=true
{% endif %}
```

## اجرا

فقط در محیط آزمایشی Debian/Ubuntu، پس از اصلاح Inventory و بررسی مسیرها اجرا کنید.

```bash
ansible-playbook -i inventory.ini playbook.yml --syntax-check
ansible-playbook -i inventory.ini playbook.yml --check --diff
ansible-playbook -i inventory.ini playbook.yml --ask-become-pass
```

> [!NOTE]
> `--check` همیشه رفتار واقعی ماژول‌ها را کاملاً شبیه‌سازی نمی‌کند. `fetch` فایل را روی کنترل‌نود ذخیره می‌کند.

**نتیجه:** اجرای مجدد، تا وقتی ورودی تغییر نکرده، نباید محتوای تنظیمات را تغییر دهد.
