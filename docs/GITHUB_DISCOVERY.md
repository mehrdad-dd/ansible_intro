## Useful discovery habits
- A clear H1, meaningful section headings, and human-readable file names beat keyword stuffing.
- Each lesson links to its language counterpart, the index, and one authoritative documentation page.
- Keep the README truthful, runnable, and stable; repair broken links and investigate CI failures promptly.
- Consider a small, accurate description and links in the GitHub About sidebar.
- GitHub and search engine indexing are independent; no ranking or inclusion can be guaranteed.
