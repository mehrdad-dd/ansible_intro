# Security / امنیت

**فارسی:** این مخزن صرفاً آموزشی است. برای گزارش افشای اطلاعات حساس، Issue عمومی باز نکنید؛ از راه ارتباط خصوصی با نگه‌دارنده استفاده کنید. رمزها و کلیدهای افشاشده باید فوراً لغو یا تعویض شوند.

**English:** This is an educational repository. Do not report exposed secrets in public issues; contact the maintainer privately. Revoke or rotate any exposed credentials immediately.
